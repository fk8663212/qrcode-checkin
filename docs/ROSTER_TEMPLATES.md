# 校園名冊與座位模板

目前仍是一份部署對應一場活動。名冊模板與座位方式分開設定，讓校園晚宴使用公關的中文 Excel，其他活動可繼續使用一般名冊與指定桌次。

## 這場晚宴的設定

1. 管理員登入，從「活動設定」（`/admin/event-settings`）選擇「校園名冊」。
2. 座位方式選「依年級分區自由座」。
3. 在「預設單位／系所」填寫共同系所，按「儲存活動設定」。
4. 到「匯入名冊」，上傳公關提供的 `.xlsx`，匯入格式保留「自動辨識」。
5. 核對預覽的學號、姓名、年級、職稱、Email、單位與區域，再按「確認匯入」。

參加者票券顯示例如「碩一區」與「區域內自由入座」。工作人員核對、成功畫面、賓果及一般抽獎主持台同步使用區域資訊。管理總覽以各年級的實際名冊人數為分母，不平均分配座位。

原有部署初次升級時維持原模板與指定桌次；請依上述步驟切換這場活動的設定。切換模板不會自行匯入或清空名冊。

## 公關 Excel 欄位

範例：[校園 Excel](../examples/attendees-campus.xlsx)、[UTF-8 BOM CSV](../examples/attendees-campus.csv)。兩者均為 13 位虛構來賓，含同名者；碩一 5 人、碩二 4 人、博一 3 人、教職員 1 人。

| 公關欄名 | 系統欄位 | 規則 |
| --- | --- | --- |
| 姓名 | `name` | 必填，最多 100 字；允許同名 |
| 年級 | `grade` | 選填，最多 30 字；依年級分區時作為分組來源 |
| 學號 | `attendee_id` | 必填，最多 64 字；作為唯一名冊編號，重匯更新同一人 |
| 職稱 | `title` | 選填，最多 80 字 |
| 電子郵件地址 | `email` | 選填，最多 254 字；供後台與票券發送清單使用 |

欄位順序可調整。亦可使用「電子郵件／Email」、「單位／系所」、「區域」等已定義欄名；同一系統欄位不可重複提供兩種別名。未知或重複欄位會在預覽列出錯誤。

無學號的老師或臨時來賓，在學號欄填主辦方固定編號，例如 `GUEST-001`；也可將該欄命名為「參加者編號」。不要用姓名猜測同一人，亦不要每次匯入產生新的編號。教職員的年級可填「教職員」，或在管理頁指定「教師區」。

學號／編號含前導 0 時，建議在 Excel 使用文字格式。系統會保留文字 ID，亦支援整數儲存格的純零顯示格式（例如 `000000`）；Excel 已經遺失的數字無法憑空還原，請在預覽核對。超過可安全識別範圍的數字或公式會拒絕匯入。

## Excel 與 CSV 的檔案限制

- `.xlsx` 或 UTF-8 CSV，可帶 BOM；每檔 1 MB 以下，單次及整體名冊最多 200 人。
- Excel 只保留一張非空白名冊工作表，第一個非空白列為標題。格式範圍最多 1000 列、20 欄；不支援公式、錯誤值、巨集、加密及舊版 `.xls`。
- 匯入只讀取資料，不執行 Excel 公式或載入外部連結。ZIP 內容亦有限制；錯誤檔案不會部分寫入。
- 一般活動模板仍支援 `attendee_id,name`，選填 `affiliation,table_no,grade,title,email,seating_area`。可在匯入頁下載一般 CSV。

## 重匯與資料保留

- 同一 `attendee_id` 更新同一人；姓名相同但編號不同視為不同人。Email 可以重複或留白，不用來合併名冊。
- 校園模板未提供單位欄時，使用活動設定的預設系所。明確提供空白單位欄時，會將單位清空。
- 新增的年級、職稱、Email、指定區域，未提供欄位時保留既有值；有提供欄位但留白時清空。校園名冊沒有桌次欄時保留原桌次，以供日後切回桌次模式。
- 一般英文名冊沿用原行為：省略桌次欄會清空桌次；省略單位欄使用活動預設單位（未設定時為空白）。
- 既有隨機票券 token、報到、首次操作者及賓果卡均保留。學號與 Email 不作為 QR 憑證。
- 預覽有效 15 分鐘，綁定管理員；名冊或活動模板設定在預覽後改變，需重新預覽。

## 可選的座位方式

| 方式 | 分組來源與票券呈現 |
| --- | --- |
| 指定桌次 | 使用 `table_no`，沿用各桌報到統計 |
| 依年級分區自由座 | 優先使用指定區域，未指定時使用年級，例如「碩一區」；同區自由入座 |
| 依名冊區域自由座 | 使用中文「區域」或英文 `seating_area`，同區自由入座 |
| 全場自由入座 | 不指定個人桌次或區域，顯示全場報到統計 |

年級或區域缺漏者顯示「現場安排」，另列未安排區域，不會自動分配到其他組。這是按名冊分區，沒有座位容量、座號或搶位功能。外籍生可切換英文介面；年級與區域名稱照主辦方資料顯示。

一般抽獎會保存抽出當下的座位資訊，後續修改名冊或切換模板不會改寫得獎歷史。既有桌次得獎紀錄仍按原桌次保留。

## Email 與隱私

管理員可在名冊與個人管理頁查看、修改 Email。匯出的票券連結清單包含 Email，供主辦方自行逐一發送；系統不自動寄信。

參加者 API 只回傳本人票券及座位資訊，不提供學號或 Email。工作人員可用姓名／學號查票，無票券連結及 Email 清單匯出權限。公開投影仍以卡號顯示得主。設定與名冊寫入均驗證登入、權限及 CSRF，模板調整留下前後值與操作者稽核。

## 升級與驗證

新增 Excel 讀取套件，更新 Docker 部署時需先完成一致性備份，再更新程式並重建應用程式映像，例如既有 Compose 的 `docker compose up -d --build`。僅 restart 舊映像不會安裝新套件。

正常啟動時自動新增活動設定資料表、名冊補充欄位及抽獎座位快照欄位。既有編號、票券及歷史不重建；舊備份還原後，重新啟動可完成新增欄位。模板與連結設定均隨 SQLite 一致性備份保存。

```sh
.venv/bin/python -m pytest -q tests/test_campus_roster.py
.venv/bin/python -m scripts.campus_browser_smoke
```

瀏覽器驗證使用隔離名冊與正常登入，涵蓋 Excel 預覽／確認、實際年級分母、繁英區域票券、工作人員報到、原票領賓果卡、抽獎區域及切回桌次模板。實際公關檔案、正式名冊、實體手機與現場區域指引仍須由主辦方驗收。
