# iPhone／Android 實機驗收

目前狀態：**所有實體裝置、真實鏡頭、現場 Wi-Fi／行動網路測試尚未執行**。桌面 WebKit／Chromium 的手機尺寸模擬與合成相機影像，不能替代此驗收。請在活動前使用與現場相同的 HTTPS 網域、手機及網路完成。

## 主辦方與發送人員

- [ ] 以 UTF-8 CSV 匯入正式名冊，預覽新增／更新數及錯誤；確認前未寫入。
- [ ] 不同編號的同名者皆存在；重匯不新增重複人，也不變更已發票券。
- [ ] 點選個人連結、複製並透過 LINE／Email 發送；`#` 後憑證未被裁掉。
- [ ] LINE 內建瀏覽器開票成功；若相機或頁面有問題，能改用 Safari／Chrome 開啟。
- [ ] 管理員下載的 QR PNG、票券頁 QR，皆可由工作人員掃描。
- [ ] 掃描前、單純開票及訊息預覽，都不會完成報到。

## 工作人員（兩種手機各做一次）

- [ ] 各自登入自己的工作人員帳號，顯示正確帳號。
- [ ] HTTPS 頁面可請求權限並開啟後鏡頭；不誤用前鏡頭。
- [ ] 拒絕權限後，有中文提示；可在系統設定重新授權並再次開啟。
- [ ] 已有其他 App 使用相機時，可理解錯誤並使用搜尋備援。
- [ ] 從另一支手機螢幕掃 QR，在室內低光、反光、不同亮度與距離下可辨識。
- [ ] 辨識後暫停掃描，先顯示姓名、編號、單位、桌次與目前狀態。
- [ ] 按確認之前，後台仍為未報到；確認成功後，姓名與桌次清楚可見。
- [ ] 按「繼續下一位」可恢復掃描；連續報到 20 人無卡住或鏡頭未釋放問題。
- [ ] 重複掃描顯示已報到、原時間、原操作者；總人數不增加。
- [ ] 兩支手機同時確認同一票，只有一支顯示首次成功，另一支顯示已報到。
- [ ] 姓名／編號搜尋可處理同名者，人工核對後才確認。
- [ ] 工作人員不能開啟管理頁、匯出、補發、撤回或管理帳號。

## 異常與恢復

- [ ] 確認前關網路，再按確認：沒有成功畫面；提示尚未確認，可安全重試。
- [ ] 送出時切換飛航或斷 Wi-Fi：畫面不得自行判定成功；復線重試後只保留一筆。
- [ ] 切換 Wi-Fi／行動網路、切換 App、鎖屏再回頁，可重新開相機並繼續操作。
- [ ] 登入過期／帳號被停用時，操作被拒絕，可重新登入或聯絡管理員。
- [ ] 不完整、外部活動、已補發票券皆有中文錯誤，無法核銷。
- [ ] 管理員撤回需原因及勾選；撤回歷史與原操作者可查。
- [ ] 補發後舊票立即失效，新票保留同一人的資料、報到狀態與歷史。
- [ ] 若票券被轉傳，現場仍需核對本人；第一版是持有憑證者可讀的票券，沒有參加者身分登入。

## 開場前的伺服器驗收

- [ ] Oracle ARM VPS 完成 Docker build／啟動，HTTPS 憑證有效，無混合內容。
- [ ] 容器重建（保留 volume）與 VPS 重啟後，名冊、票券、帳號、歷史都保留。
- [ ] 檢查資料庫、備份與匯出檔不能從公開網址下載。
- [ ] 備份到私有外部儲存，並在隔離資料庫演練還原；核對總人數及已報到人數。
- [ ] 門口 Wi-Fi 和手機備援網路均可連到伺服器；預備第二台工作手機。
- [ ] 全程最多 200 人；記錄現場尖峰掃描的回應時間（目標由主辦方確認）。

本版不支援離線核銷、離線同步、自動寄信、多活動共用資料庫。網路無法恢復時，先採主辦方的紙本流程，恢復後由授權人員核對與補登。

## 賓果整合追加實機驗收

以下尚待實際設備驗證；瀏覽器尺寸模擬不代表已完成。

- [ ] iPhone Safari、Android Chrome：未報到票券沒有領卡入口，報到後更新狀態可從原票券領卡。
- [ ] 同票重開、手機換瀏覽器／裝置均恢復原卡及已保存勾選。
- [ ] 主持台設定本局獎品份數、儲存後重整；玩家規則與投影名額同步，首次開獎後無法再改份數。
- [ ] 建立下一局時選擇不同的獎品份數；手機數字輸入、取消與確認可正常操作，舊局份數保留。
- [ ] 主持台開獎動畫、減少動態效果設定、背景返回及投影設備全螢幕。
- [ ] 領卡回應遺失後安全重試；Wi-Fi／行動網路切換與暫存勾選恢復。
- [ ] 票券補發與報到撤回後，既有賓果頁失去操作權，新有效票券可依報到資格恢復。
- [ ] 領獎時以主持台姓名、桌次、卡號核對本人，投影沒有完整名冊姓名。
- [ ] 下一局、歷史局次、領獎紀錄、完整備份／還原演練。

## 一般抽獎追加實機驗收

以下尚待實際設備驗證；自動化瀏覽器與多程序測試不代表已完成。

- [ ] 管理員在手機新增獎品、設定份數及一次抽出人數，規則未儲存時不能抽獎。
- [ ] 票券顯示本人抽獎號碼，與公開投影一致；未報到來賓不在候選池。
- [ ] 核對本輪不重複、先前得主參加及排除賓果三項規則；第一次抽獎後鎖定。
- [ ] 實際 Wi-Fi／行動網路中斷時不出現未經確認的成功結果；同分頁安全重試不多抽。
- [ ] 得主放棄時填原因重抽，原紀錄及替補保留；無候選人時原得獎不變。
- [ ] 現場核對本人並標記領獎，開新一輪加碼、查看歷史及匯出 CSV。
- [ ] 使用實際投影設備驗證卡號可讀性、全螢幕、背景返回與網路同步。
- [ ] 主持台與投影滾動後才揭曉新得主，動畫期間無法再抽；開啟減少動態效果時直接顯示，重整不重播舊結果。

## 參加者雙語追加實機驗收

以下尚未在實體設備執行；請兩種手機各做一次。

- [ ] 英文瀏覽器首次開票顯示英文，中文瀏覽器顯示繁體中文；頁首能手動切換並記住選擇。
- [ ] LINE 發送的完整英文票券連結 `?lang=en#憑證` 能正確開啟；切換後原 QR、姓名與桌次保留。
- [ ] 窄螢幕、較大的系統字級下，按鈕／語言切換與桌次清楚，沒有整頁橫向溢出。
- [ ] 切換語言不會自動報到或多領一張卡；原卡、已保存勾選與中獎狀態保留。
- [ ] 外籍生可理解待報到／已報到、票券失效、尚未開放領卡、斷線與領獎提示。
- [ ] 補發後舊票在兩種語言都失效，新票可恢復同一局原卡；工作人員及後台仍為中文。
- [ ] 主辦方填寫的雙語活動資訊與獎品完整可讀；投影選 English 後，動態開獎、得主及領獎標記均為英文。
