# 一般抽獎與現場加碼

一般抽獎與賓果共用同一場活動的名冊及報到狀態，分別保存遊戲與得獎紀錄。管理員可管理獎品、抽獎、標記領獎及辦理重抽；工作人員及持票來賓沒有主持權限。不需要另行上傳名單或部署服務。

| 介面 | 路徑 | 權限 |
| --- | --- | --- |
| 抽獎主持台 | `/raffle/host` | 管理員登入 |
| 公開投影 | `/raffle/display` | 公開唯讀 |
| 本人抽獎號碼 | 原電子票券 `/ticket#個人憑證` | 本人有效票券 |

## 第一輪操作

1. 管理員登入，從導覽列按「一般抽獎」。初始輪次為「一般抽獎」，獎品清單為空；開啟頁面不會抽獎。
2. 核對「本輪抽獎規則」，設定輪次名稱並儲存。只抽已完成報到者；第一次抽獎後資格規則鎖定。
3. 輸入獎品名稱及份數，按「新增獎品」。每個獎品可設定 1～200 份，可隨時臨時加獎。
4. 在對應獎品填「本次抽出人數」，按「抽出得主」。一次可抽 1～200 位；候選人或剩餘份數不足時整批拒絕，不會只抽出一半，也不會自動放寬規則。
5. 只有伺服器確認交易完成後才顯示「已確認抽出」。主持人看到姓名、參加者編號及桌次，公開投影只顯示獎品與卡號。
6. 來賓可在原票券查看自己的抽獎號碼，例如 `P001`，與賓果卡號一致。此號碼僅用於公告，不能代替安全票券憑證，不能用它讀取他人票券或報到。
7. 領獎時核對本人，按「標記領獎」。記錄領獎時間；取消標記需要再次確認，異動均保存在稽核紀錄。

## 抽獎與揭曉動畫

主持台及投影會以黑金色號碼滾動、光暈與金色飄落效果揭曉得主，約 3 秒。滾動數字只作視覺呈現，得主以伺服器保存結果為準；倒數期間保留上一批名單，結束後才列出新得主。動畫期間，本頁的下一次抽選及其他寫入暫停。

投影依伺服器時間播放剩餘倒數，背景頁返回會補查；重新整理、首次開頁或補查多批結果時直接顯示已保存名單，不重播舊抽獎。系統開啟「減少動態效果」時直接揭曉。網路逾時仍保留原本的待確認提示及安全重試流程。

## 三項資格開關

| 設定 | 預設 | 意義 |
| --- | --- | --- |
| 本輪允許同一人重複中獎 | 關閉 | 關閉時，本輪已獲得任何一般獎的來賓不再進入本輪候選池；開啟後可在後續抽選再次中獎 |
| 先前一般抽獎輪次的得主也可參加 | 關閉 | 關閉時，排除所有先前輪次的有效一般獎得主；加碼希望人人重新有一次機會時可開啟 |
| 排除曾在賓果中獎的來賓 | 關閉 | 開啟時，排除活動中任一局的賓果得主；是否領獎不影響排除 |

同一批抽出多位時，人選永遠不重複，即使開啟「本輪允許重複」也一樣。不同編號的同名來賓視為不同人。已報到後被撤回的人立即失去後續抽選資格，既有得獎紀錄保留。

常用方式：一般獎三個開關均關閉；加碼讓先前得主重新參加一次，僅開啟第二項；希望所有已報到者在本輪可多次中獎，開啟前兩項。規則一旦鎖定，需另開新一輪才能改變。

## 臨時加獎與調整份數

隨時可新增獎品。各獎品的「修改獎品／增加份數」可調整名稱與總份數，但不能減到有效中獎份數以下。抽選與份數更新共用 SQLite 寫入交易，多位管理員同時操作也不會超發。修改會記下管理員及前後值。

## 重抽與原紀錄

「允許重複中獎」控制候選資格；「撤銷並重抽」用於得主放棄或核對不符，兩者分開處理。

1. 在尚未領獎的有效得獎紀錄按「撤銷並重抽」。已領獎者需先核對並取消領獎標記。
2. 填寫原因，勾選確認，再按「確認重抽」。
3. 原得主不參加這一次替補；其他人仍須符合本輪資格。抽出一位替補、撤銷原紀錄及保存關聯在同一筆交易完成。
4. 若沒有符合資格的替補，整筆操作取消，原得獎保持有效。
5. 原紀錄仍可查看，含撤銷時間、管理員、原因與替補關聯；不刪除歷史。被撤銷的得獎不占獎品份數，也不再計入「已中一般獎」排除條件，因此往後仍可能被抽中。

歷史輪次可以補登／取消領獎標記；抽選、重抽及獎品設定只能在目前輪次進行。

## 加碼／下一輪

按「開啟新一輪抽獎」，輸入名稱及三項規則，再完整輸入「開啟新一輪抽獎」確認。舊輪次立即結束，歷史與未領獎紀錄保留；新輪次有獨立獎品清單，請重新新增獎品。從「檢視輪次」切回舊輪可核對歷史。

## 網路中斷與安全重試

抽選及重抽都使用獨立操作識別碼。請求前送出失敗、伺服器已寫入但回應遺失、5xx 或逾時，都不另產生抽選識別碼。主持台會顯示「上次抽獎結果尚未確認」，其他寫入暫停；請按「確認上次操作／安全重試」，相同操作只會抽一次。安全驗證過期或登入失效也保留待確認操作，重新登入後使用同一瀏覽器分頁查證。

待確認操作暫存在本分頁的 `sessionStorage`，重新整理仍保留；請勿關閉分頁或清除瀏覽器資料。瀏覽器不允許此儲存時，原頁記憶體中的重試仍有效，重新整理後須先核對歷史，切勿直接補抽。這是線上抽獎，沒有離線抽選或同步功能。

## 匯出、備份與部署

主持台可 POST 下載全部輪次的 CSV 得獎報表，包含撤銷紀錄、原因、替補關聯、抽出與領獎時間（Asia/Taipei）。CSV 會處理公式字元。JSON 完整紀錄另含候選人編號與保存的抽選結果；兩種匯出只有管理員可下載，不包含票券 token、密碼或 session，請私下保存。

新增 `raffle_rounds`、`raffle_prizes`、`raffle_draws`、`raffle_winners` 四張資料表；原名冊、票券、報到及賓果資料保留。更新前依 README 使用 SQLite Backup API 一致性備份，再停止所有本專案 worker、更新程式並重啟。既有 Docker 映像建置及持久化資料卷設定適用，無新增套件或額外公開服務。

`backup-db` 涵蓋抽獎；`restore-db` 接受抽獎功能加入前的完整備份，重啟時補齊空白抽獎資料表。只有部分抽獎資料表的備份會被拒絕。還原覆寫備份時間之後的結果並撤銷帳號登入；停止服務後還原，核對報表與實際已發獎品，再繼續活動。
